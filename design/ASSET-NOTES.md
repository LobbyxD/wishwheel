# Wishwheel generated visual assets

Built-in image_gen mode was used for all three assets. Originals were preserved and the selected images copied into this workspace. All images were visually inspected.

## Production files
- `wishwheel-icon-master.png`: Square wheel icon, 1254x1254. Deep evergreen field; alternating evergreen, warm ivory and red wheel slices; gold ring, star hub and red pointer. Delivery-size PWA derivatives are public/icon-192.png, public/icon-512.png and public/apple-touch-icon.png.
- `holiday-scene.png`: Square Christmas scene, 1254x1254. Evergreen tree, gold star and ribbon, three warm ivory/terracotta/green gifts. The optimized runtime version is public/assets/holiday-scene.webp, used for the welcome card and hidden-wheel cover. Background is opaque evergreen.

## Design reference
- `interface-reference.png`: Generated desktop + mobile UI reference, 1536x1024. Inspiration only, not screenshot of implemented app. Generated mockup includes illustrative names and copy; actual app must use functional real data.

## Prompt set

### Icon
Use case: logo-brand. Asset type: square iPhone web app icon for a modern Christmas gift roulette app called Wishwheel. Generate one premium minimal 3D icon, no text: a friendly circular six-slice prize wheel, alternating rich evergreen, muted cranberry and warm ivory segments, fine satin-gold outer rim, tiny gold star at center and a small warm-red pointer at top. Wheel centered and filling 70 percent of square. Deep evergreen flat background extends fully to all edges, subtle soft studio shadow. Refined modern tactile materials, simple silhouette legible at 48 pixels. No surrounding objects, no lettering, no gradients outside icon, no device mockup, no rounded-square border, no white frame. High quality 1024 square.

### Hero

A single soft curved ivory snow platform underneath. Deep muted evergreen seamless backdrop. Full scene contained within central 75 percent of square so it works cropped in a circular wheel cover and a rounded website card. Modern sophisticated playful aesthetic, refined proportions, no people, no lettering, no watermark, no UI, no borders, no clutter, no realistic glitter. Soft studio lighting, gently luminous golden highlights, matte ceramics and satin materials. Square image.
